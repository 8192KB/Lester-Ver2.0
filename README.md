# Lester-VER2.0
GTA Online Heist Hacking(Minigame) Macro

Special thanks to [RedHeadEmile](https://github.com/RedHeadEmile/GTA-V-Heist-Help) for `Fingerprint Scanner` and `Retro Fingerprint Scanner`

# 사용법
- `F4`: 프로그램 종료
- `F5`: 지문 스캐너 (다이아몬드 카지노 습격)
- `F6`: 금고 키패드 크래커 (다이아몬드 카지노 습격, 다음 판은 이전 위치에서 시작)
- `F7`: 금고 키패드 크래커 2 (코르츠 센터 습격용, 매번 1행에서 시작)
- `F8`: 지문 복제기 (카요 페리코 습격)
- `F9`: 볼트랩 전압 해킹 (카요 페리코 습격)
- `F10`: HackConnect 숫자/IP 찾기 (여러 임무 공용)
- `F11`: BruteForce 비밀번호 맞추기 (여러 임무 공용)
- `F12`: 인식 화면 저장 (문제 진단용)

# Setup
- Download or Clone the repository
- Install the requirements `pip install -r requirements.txt`
- Run `python main.py`

# Warning
- `Python 3.8` is the recommended python version for this repository
- `1920x1080` resolution is recommended but other resolutions **might** work
- 다이아몬드 카지노에서는 마지막 패턴이 나타났을 때 `F6`을 누르세요.
- 코르츠 센터 습격에서는 마지막 패턴이 나타났을 때 `F7`을 누르세요.
